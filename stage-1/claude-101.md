# Claude 101

Quick intro course from Anthropic, general overview of working with Claude.

## What I took from it:

- **Claude Cowork**: agentic mode for multi-step tasks. I set up a weekly recurring task and let it run without manual oversight. Hadn't worked with AI tools this way before.
- How Claude gets used in a corporate/enterprise context, not just as a chat tool for personal tasks.

## Takeaway:

Solid entry point from zero, but basic level, no depth on capabilities/limitations (that's the next course).
